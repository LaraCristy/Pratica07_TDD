# Prática 07 – PoC Clientes com TDD e Git

## Sobre a atividade:

Esta atividade faz parte da disciplina de Gestão e Qualidade de Software e tem como objetivo desenvolver, em Java, as classes Cliente, FaturaCliente e ContaCliente.

Durante o desenvolvimento, estamos utilizando a metodologia TDD para criação e execução de testes, além do Git e GitHub para organizar e compartilhar as alterações.

## Tecnologias utilizadas:

- Java 8
- Maven
- JUnit 5
- Git e GitHub

## Desenvolvimento

A atividade está sendo realizada utilizando a metodologia TDD, seguindo três etapas:

-RED: criar um teste que apresente falha.

-GREEN: implementar o código para fazer o teste passar.

-REFACTOR: melhorar o código sem alterar seu funcionamento.

## Organização do Git

Estamos utilizando branches para desenvolver as funcionalidades separadamente. As alterações são enviadas por Pull Requests, que precisam ser revisados e aprovados pela outra integrante antes de serem adicionados à branch main.
